## 📌 Highlight Projects

### 👕 [Uniform Recognition System](https://github.com/BaoAnh109/Uniform-Recognition-System)
A practical computer vision project developed to recognize uniforms from images, with the goal of classifying or identifying subjects based on clothing-related visual features in specific environments.

**Key Highlights:**
- Performed image data processing and analysis
- Designed recognition logic using visual feature patterns
- Applied programming to address a practical real-world use case
- Explored core concepts in computer vision and image processing

**Tech Stack:**
- `Python`
- `YOLO / Ultralytics`
- `Computer Vision`
- `Image Processing`
- `Object Detection & Segmentation`
- `BOTSort Tracking`

> Through this project, I improved my analytical thinking, strengthened my problem-solving approach, and gained practical experience in building applied software solutions.

### 🎬 [CineHub](https://github.com/BaoAnh109/CineHub)
A cinema booking web project developed to simulate a modern ticket reservation experience, covering core user flows such as movie browsing, showtime selection, seat booking, combo selection, authentication, profile management, and ticket tracking.

**Key Highlights:**
- Modeled a realistic cinema booking process through multiple connected pages
- Separated interface, business interaction logic, and mock data into a structured project layout
- Implemented dedicated modules for authentication, booking flow, seat selection, support features, and admin-related screens
- Used JSON datasets to simulate application data in a maintainable and extensible way
- Strengthened practical skills in front-end architecture, interaction design, and modular JavaScript organization

**Tech Stack:**
- `HTML5`
- `CSS3`
- `JavaScript`
- `JSON`
- `Multi-Page Application`
- `Front-End Architecture`

> Through this project, I enhanced my front-end engineering mindset, especially in organizing code, designing user flows, and building maintainable web interfaces for practical use cases.

### 🚗 [DO_AN_DSA](https://github.com/BaoAnh109/DO_AN_DSA)
A data-structure-oriented software project developed to simulate a parking lot management system for **AEON Tan Phu**, focusing on vehicle management, staff access control, operational workflows, and revenue statistics in a structured console-based application.

**Key Highlights:**
- Developed a parking lot management system with role-based access for **Manager** and **Staff**
- Implemented core features for vehicle handling, employee management, login control, and operational menu processing
- Organized the project into separate modules such as `AccessControl`, `Menu`, `Xe`, and `SNode` for clearer logic separation
- Applied file-based data storage using text files for users and vehicle information
- Explored practical usage of **data structures** in handling lists, searching, deleting, sorting, and processing management data
- Added revenue statistics features by day, month, year, and custom date ranges for operational tracking

**Tech Stack:**
- `C++`
- `C`
- `Data Structures and Algorithms`
- `File Handling`
- `Console Application`
- `Visual Studio Solution`

> Through this project, I improved my understanding of data structures in real-world problem solving, strengthened my thinking in modular program design, and gained practical experience in building a management-oriented software system.
